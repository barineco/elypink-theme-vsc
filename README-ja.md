# Elypink Theme

Visual Studio Code / VSCodium 用のピンク系テーマです。

![Elypink Light](images/elypink-light.png)

![Elypink Dark](images/elypink-dark.png)

## 特徴

- ピンクを基調としたカラーパレット
- コントラスト最適化 — WCAG/APCAコントラスト基準を計算してデザイン
- カラーフィルタによるバリエーション
- ライト＆ダークモード

## テーマ一覧

### ライト

| テーマ | 説明 |
|-------|------|
| Elypink Light | 標準のピンクテーマ（推奨） |
| Elypink Light (Faded) | 色相反転によるシアン系UI |
| Elypink Light (Spring) | 赤みのあるピンクオーバーレイ |
| Elypink Light (Summer) | 青のオーバーレイ |
| Elypink Light (Diamond) | シアンのオーバーレイ |

### ダーク

| テーマ | 説明 |
|-------|------|
| Elypink Dark | 標準のピンクダークテーマ |
| Elypink Dark (Faded) | 色相反転によるシアン系UI |

## インストール

### VS Code / VSCodium

拡張機能マーケットプレイスで「Elypink」を検索してください。

### 手動インストール

1. [Releases](https://github.com/barineco/elypink-theme-vsc/releases) から `.vsix` ファイルをダウンロード
2. 実行: `code --install-extension elypink-theme-*.vsix`
