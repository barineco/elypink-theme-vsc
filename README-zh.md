# Elypink Theme

适用于 Visual Studio Code 和 VSCodium 的粉色系主题合集。

![Elypink Light](images/elypink-light.png)

![Elypink Dark](images/elypink-dark.png)

## 特点

- 粉色调色板 — 温暖柔和的视觉体验
- 对比度优化 — 基于 WCAG/APCA 对比度标准设计，确保可读性
- 多种变体 — 通过色彩变换提供多种风格
- 明暗模式 — 每种变体都提供明亮和暗色两种模式

## 主题列表

### 明亮

| 主题 | 说明 |
|------|------|
| Elypink Light | 标准粉色主题（推荐） |
| Elypink Light (Faded) | 色相反转的青色系界面 |
| Elypink Light (Spring) | 暖红粉色叠加 |
| Elypink Light (Summer) | 冷蓝色叠加 |
| Elypink Light (Diamond) | 清新青色叠加 |

### 暗色

| 主题 | 说明 |
|------|------|
| Elypink Dark | 标准粉色暗色主题 |
| Elypink Dark (Faded) | 色相反转的青色系界面 |

## 安装

### VS Code / VSCodium

在扩展市场中搜索「Elypink」。

### 手动安装

1. 从 [Releases](https://github.com/barineco/elypink-theme-vsc/releases) 下载 `.vsix` 文件
2. 执行：`code --install-extension elypink-theme-*.vsix`
